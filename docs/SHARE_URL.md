# 설정 공유 URL (해시)

KR ETF Lab은 주소 **해시(`#`)** 에 핵심 설정을 넣어 같은 화면을 복원할 수 있습니다.
서버로 보내지 않으며, 길이를 짧게 유지하기 위해 값이 기본일 때는 키를 생략합니다.

형식: `https://…/index.html#v=1&…`

## 인코딩 키

| 키 | 의미 | 예 |
|---|---|---|
| `v` | 스키마 버전 | `1` |
| `preset` | 프리셋 id (보유와 일치할 때 우선) | `kAllWeather` |
| `h` | 커스텀 보유 `코드*비중`을 `_`로 연결 | `069500*40_133690*40` |
| `p` | 기간 | `1y` `3y` `5y` `10y` `max` `custom` |
| `ps` `pe` | custom일 때 시작·종료일 | `2016-01-01` |
| `rb` | 리밸런싱 | `Q` `Y` `M` `MOM` `MOM12_1` `XSMOM` `DMOM` `N` |
| `lb` `tn` | 모멘텀 룩백·상위 N | `1` `3` |
| `w` | 비중 방식 (`invVol`만 명시) | `invVol` |
| `ma` `mw` | MA 오버레이·창 | `1` `200` |
| `cash` | 안전자산 코드 | `153130` |
| `rh` `rhm` `rhp` | 국면 헤지 on, 모드, 상한% | `1` `inverse` `15` |
| `gold` `gsp` `glb` `gc` | 금 슬리브 on, %, 룩백, 종목 | `1` `15` `1` `132030` |
| `band` `bp` | 리밸런싱 밴드 on, 밴드% (1–10) | `1` `5` |
| `vt` `vtp` `vtw` | 변동성 타깃 on, 목표%(5–20), 룩백 거래일 | `1` `10` `60` |
| `st` `stm` `stlb` | 슬리브 추세 on, 모드(`abs`/`ma`), 절대 룩백 | `1` `abs` `1` |
| `tc` | 거래비용(bps). 기본 10 생략. 0–50 | `0` `25` |
| `dca` `ic` `mo` | 월적립 on, 시작원금, 매월 | `1` `10000000` `500000` |
| `tr` | (폐지) 과거 링크 호환용으로 읽기만 하고 무시 — 시세가 수정주가라 TR 가산은 이중 계산 | `1` |
| `acct` `ptr` | 계좌·연금세율 | `pension` `0.044` |

복원 시 시세를 로드한 뒤 백테스트를 한 번 실행합니다.
CSV 내보내기(결과 화면)는 보유 비중·파라미터·KPI·연도별·공통기간/잘린 종목을 포함합니다.

투자 자문이 아닙니다. 과거 시뮬 결과만 공유합니다.

## 거래비용·수익률 기준

- 거래비용: 리밸런싱마다 `value -= value × TO × rate`, `TO = 0.5 × Σ|w_new − w_old|`(편도 회전율). 기본 rate=0.1%(10bps).
- CSV `params.tradeCost` / `kpi.totalCostDrag` 에 비용률·누적 드래그를 넣습니다.
- 수익률 기준: 수정주가 기준(분배금 세전 재투자 효과 포함) · 세금 미반영 · 과거 시뮬. 합성 TR·분배 가산은 하지 않습니다(이중 계산).
- 배당 현금흐름 탭: `#div` 로 바로 열기, `#div=divSample`(배당 포트폴리오 예시) · `#div=schdVsKr`(SCHD 직투 vs 국내상장)로 프리셋 실행.

## 시작일 민감도 (배치6)

히트맵은 공유 URL에 넣지 않습니다. 결과 화면의 「민감도 보기」로만 계산하며, 현재 설정·고정 종료일 기준 과거 시뮬입니다.
