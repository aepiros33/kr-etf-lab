# 설정 공유 URL (해시)

KR ETF Lab은 주소 **해시(`#`)** 에 핵심 설정을 넣어 같은 화면을 복원할 수 있습니다.
서버로 보내지 않으며, 길이를 짧게 유지하기 위해 값이 기본일 때는 키를 생략합니다.

형식: `https://…/index.html#v=1&…`

## 인코딩 키

| 키 | 의미 | 예 |
|---|---|---|
| `v` | 스키마 버전 | `1` |
| `preset` | 프리셋 id (보유와 일치할 때 우선) | `kAllWeather` |
| `h` | 커스텀 보유 `코드*비중`을 `_`로 연결 | `069500*40_133690*40` |
| `p` | 기간 | `1y` `3y` `5y` `10y` `max` `custom` |
| `ps` `pe` | custom일 때 시작·종료일 | `2016-01-01` |
| `rb` | 리밸런싱 | `Q` `Y` `M` `MOM` `MOM12_1` `XSMOM` `DMOM` `N` |
| `lb` `tn` | 모멘텀 룩백·상위 N | `1` `3` |
| `w` | 비중 방식 (`invVol`만 명시) | `invVol` |
| `ma` `mw` | MA 오버레이·창 | `1` `200` |
| `cash` | 안전자산 코드 | `153130` |
| `rh` `rhm` `rhp` | 국면 헤지 on, 모드, 상한% | `1` `inverse` `15` |
| `gold` `gsp` `glb` `gc` | 금 슬리브 on, %, 룩백, 종목 | `1` `15` `1` `132030` |
| `band` `bp` | 리밸런싱 밴드 on, 밴드% (1–10) | `1` `5` |
| `vt` `vtp` `vtw` | 변동성 타깃 on, 목표%(5–20), 룩백 거래일 | `1` `10` `60` |
| `st` `stm` `stlb` | 슬리브 추세 on, 모드(`abs`/`ma`), 절대 룩백 | `1` `abs` `1` |
| `tc` | 거래비용(bps). 기본 10 생략. 0–50 | `0` `25` |
| `dca` `ic` `mo` | 월적립 on, 시작원금, 매월 | `1` `10000000` `500000` |
| `tr` | (폐지) 과거 링크 호환용으로 읽기만 하고 무시 — 시세가 수정주가라 TR 가산은 이중 계산 | `1` |
| `acct` `ptr` | 계좌·연금세율 | `pension` `0.044` |

복원 시 시세를 로드한 뒤 백테스트를 한 번 실행합니다.
CSV 내보내기(결과 화면)는 보유 비중·파라미터·KPI·연도별·공통기간/잘린 종목을 포함합니다.

투자 자문이 아닙니다. 과거 시뮬 결과만 공유합니다.

## 거래비용·수익률 기준

- 거래비용: 리밸런싱마다 `value -= value × TO × rate`, `TO = 0.5 × Σ|w_new − w_old|`(편도 회전율). 기본 rate=0.1%(10bps).
- CSV `params.tradeCost` / `kpi.totalCostDrag` 에 비용률·누적 드래그를 넣습니다.
- 수익률 기준: 수정주가 기준(분배금 세전 재투자 효과 포함) · 세금 미반영 · 과거 시뮬. 합성 TR·분배 가산은 하지 않습니다(이중 계산).
- 배당 현금흐름 탭: `#div` 로 바로 열기, `#div=divSample`(배당 포트폴리오 예시) · `#div=schdVsKr`(SCHD 직투 vs 국내상장)로 프리셋 실행(예전 링크 호환).

## 배당 현금흐름 탭 공유 URL (div2~)

배당 탭 결과 위 「설정 링크 복사」가 아래 키로 링크를 만듭니다. 실행·막대 전환 때 주소창 해시도 같은 값으로 갱신되므로 주소를 그대로 복사해도 같은 설정이 복원됩니다(가격 모드 탭을 누르면 배당 해시는 지워짐).
가격 모드 키(`v` `preset` `h`)와 겹치지 않으며, 기본값인 키는 생략합니다. `dv=1`이 있으면 없는 토글 키는 기본값(인출·세후 막대)으로 읽고, `dv`가 없는 예전 링크(`#div=divSample`)는 프리셋 설정 그대로 실행합니다.

형식: `https://…/#div=divSample&dv=1&dm=reinvest&tx=pre`

| 키 | 의미 | 예 / 기본 |
|---|---|---|
| `div` | 배당 탭 열기 · 프리셋 id 또는 `1`(직접 선택) | `divSample` `schdVsKr` `1` |
| `dv` | 배당 해시 스키마 버전 | `1` |
| `dh` | 종목 `코드*비중`을 `_`로 연결 (프리셋 비중과 같으면 생략) | `SCHD*60_446720*40` |
| `dm` | 분배금 처리: 같은 종목 재투자 (생략 = 인출(현금으로 빼기)) | `reinvest` |
| `tx` | 막대 기준: 세전 (생략 = 세후) | `pre` |
| `dp` `dps` `dpe` | 기간(`10y` `5y` `3y` `1y` `custom`, 생략 = 최장) · custom 시작·종료일 | `custom` `2016-01-01` `2024-12-31` |
| `drb` | 리밸런싱 `Q` `Y` `M` `N` (생략 = 프리셋 값, 직접 선택은 `N`) | `Q` |
| `db` `dbp` | 밴드 리밸런싱 on · 밴드 %p(1–10) | `1` `3` |
| `dic` `dmo` | 시작 원금(생략 = 1억) · 매월 적립(생략 = 0) | `50000000` `300000` |
| `tc` | 거래비용 bps(가격 모드와 공유, 기본 10 생략, 0–50) | `25` |

## 배당 현금흐름 CSV (「결과 CSV」)

UTF-8 BOM(엑셀 한글 깨짐 방지). 구성:

1. `meta` — 생성 시각, `returnBasis`(원가격 + 실제 분배 이벤트 · 수정주가 미사용 · 배당락일 기준 월 집계 · 과거 시뮬), `taxAssumption`(일반계좌 · 미국 15% / 국내 15.4%), `fxAssumption`, `statusLegend`, `ttmDefinition`(월평균 = TTM÷12), 데이터 생성일, 공유 URL
2. `params` — 프리셋, 인출/재투자, 리밸런싱·밴드, 기간, 금액, 거래비용, 공통 시작·끝
3. `kpi` — 누적 세전·세금·세후, TTM, 총수익률(분배 포함), 가격만 수익률, 연환산, MDD, 기말 평가액
4. `holdings` — 종목별 비중·세율·**시세 기간(종목별)**·분배 데이터 범위·미확인 구간·기간 합계
5. `monthly` — 월(배당락월)별 종목별 세전·세금·세후(미국 직투는 USD·적용 환율 추가), 합계 세전·세금·세후·건수, 분배 가중 USDKRW, 상태
6. `yearly` — 연도별 합계·건수·상태·부분 연도(미국 직투 포함 시 달러 증감·환율 효과·원화 증감)

금액을 알 수 없는 칸은 숫자 0이 아니라 **`데이터 없음`**(분배 데이터 범위 밖) / **`미확인`**(정기 일정상 있어야 하나 확인 불가) 글자로 씁니다. `0`은 데이터 범위 안에서 확인된 무분배만 뜻합니다. 비교 프리셋(`schdVsKr`)은 `leg` 열로 비교 대상별 표를 나눕니다.

## 시작일 민감도 (배치6)

히트맵은 공유 URL에 넣지 않습니다. 결과 화면의 「민감도 보기」로만 계산하며, 현재 설정·고정 종료일 기준 과거 시뮬입니다.
