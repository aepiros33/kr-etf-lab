# 국면 헤지(실험) — P1 스펙

실험 트랙 전용. **기본 전략·기본 프리셋에 넣지 않는다.**
‘스마트머니/유동성 인버스’ 추천 톤·라벨 금지. UI 라벨은 **「국면 헤지(실험)」** 만 사용.

## 허용

| 항목 | 규칙 |
|---|---|
| 신호 | `069500`(KODEX 200) **그리고** `133690`(TIGER 미국나스닥100) **둘 다** 전일까지의 SMA 아래(MA↓)일 때만 헤지 소비중 |
| 룩어헤드 | 금지. SMA 창은 `asof` **미만** 거래일만 사용 (`maRiskOn`과 동일) |
| −1x 인버스 | `114800` (KODEX 인버스)만. `leveraged` 태그 유지 |
| 2X | **금지** (`252670` 등). 엔진이 거부 |
| 비중 상한 | 헤지 슬리브 ≤ **15%** (하드캡) |
| 리밸 | 헤지 비중 변경은 **월 1회**(월 경계). 기존 리밸 스케줄에 OR |
| 대체안 | 인버스 대신 현금/단기채 `214980` / `423160` 으로 위험자산 축소 (모드 `cash`) |
| 면책 | 실험·과거 시뮬레이션. 투자 자문 아님 |

## 메인 `maOverlay`와의 차별

| | `maOverlay` (메인) | `regimeHedge` (실험) |
|---|---|---|
| 신호 | 벤치 `069500` 단일 vs SMA | **069500 ∧ 133690** 둘 다 MA↓ |
| 위험오프 자산 | 안전자산(기본 `214980`), 비중 기본 100% | −1x `114800` **또는** 현금/단기채, **≤15%** |
| 기본 프리셋 | 해당 없음(토글) | 해당 없음(실험 토글). 인버스 미포함 |

## 구현 키

- 옵션: `regimeHedge`, `regimeHedgeMode` (`inverse`|`cash`), `regimeHedgePct`(≤0.15), `regimeHedgeCode`, `maWindow`
- 숫자 동기: `app.js` ↔ `agents/build_backtest.py`
- 검수: `python3 agents/reviewer.py` PASS 필수
- 브랜치: `feature/liquidity-hedge` 만. main 머지·Pages 배포는 별도 승인

## 비허용

- 2X/3X 인버스·레버리지를 헤지 코드로 지정
- 기본 프리셋·기본 전략 경로에 인버스 삽입
- ‘유동성 인버스’/‘스마트머니’ UI 문구
